# KSI-CNA-01

> Configure ALL information resources to limit inbound and outbound traffic.

## Checks

### 1.1 - Ensure that public access is not given to RDS Instance (Automated)

Verify that all RDS instances have `publicly_accessible` set to `false`.

<details>
    <summary>View Macro</summary>
    <CodeBlock language="sql">
        {check10}
    </CodeBlock>
</details>

### 1.2 - The VPC default security group should not allow inbound and outbound traffic

Verify that the default security group created in each VPC either has restrictions on allowed traffic, or has no rules

<details>
    <summary>View Macro</summary>
    <CodeBlock language="sql">
        {check11}
    </CodeBlock>
</details>

### 1.3 - Public ALBs should restrict traffic to defined ports

Verify that ALBs do not have a security group attached allowing traffic from `0.0.0.0/0` ***or*** any port number

<details>
    <summary>View Macro</summary>
    <CodeBlock language="sql">
        {check12}
    </CodeBlock>
</details>
