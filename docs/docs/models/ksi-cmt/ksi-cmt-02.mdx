# KSI-CMT-02
> Execute changes though redeployment of version controlled immutable resources rather than direct modification wherever possible.

## Checks

### 1.0 - Kubernetes images should use an immutable registry

For each Kubernetes image found in our asset inventory, verify that the ECR image it is sourced from is immutable.
