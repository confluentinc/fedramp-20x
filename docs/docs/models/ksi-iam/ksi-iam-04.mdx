# KSI-IAM-04

> Use a least-privileged, role and attribute-based, and just-in-time security authorization model for all user and non-user accounts and services.

## Checks


### 1.0 - AWS Root Accounts should not have active access credentials

Verify that the root account for each AWS account does not have active access keys or secret keys.
