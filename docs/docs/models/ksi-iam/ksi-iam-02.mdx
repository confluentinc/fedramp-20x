# KSI-IAM-02

> Use secure passwordless methods for user authentication and authorization when feasible, otherwise enforce strong passwords with MFA.

## Checks


### 1.0 - User authentication requires strong passwords

Verify that all users have at least one Okta policy attached requiring password complexity. Also verify that the
complexity requirements are strong enough to prevent brute-force attacks.
