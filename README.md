# Description
This repository contains DBT models used to evaluate evidence that has been aggregated from various sources to determine compliance for the [FedRAMP 20x framework](https://www.fedramp.gov/20x/standards/). Although the macros and models in this repository is used by Confluent Inc., it can be modified to apply to any provider according to the terms in the [LICENSE](LICENSE) file. 

# Navigating this repository

Reference information in the following order:

1. [Methodology](METHODOLOGY.md)
1. [Model for FedRAMP 20x Low](/models/fedramp_ksis.sql)
1. From the model in 2., find the corresponding macros in the [macros](/macros/) directory

*Continue below if you are reviewing on behalf of the Program Management Office*
1. Navigate to the private repository provided as part of our submission intake form.
1. The **Artifacts** directory contains everything related to our submission.
1. The 3PAO Assessment Files contains the human readable report: "SRTM" file.
1. The other subdirectories prefixed with "**FRR**" and "**KSI**" contains evidence and supporting documents.
